# 📊 Análise de Vendas com Python e Pandas

Projeto desenvolvido com Python utilizando a biblioteca Pandas para análise de dados de vendas, faturamento e desempenho de lojas.

## 🚀 Objetivo

O objetivo deste projeto é praticar análise de dados utilizando Python, realizando:

- Importação de arquivos CSV e Excel
- Tratamento e manipulação de dados
- Análise de faturamento
- Organização de informações
- Visualização de resultados
- Formatação de dados financeiros

---

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 📈 Análises realizadas

✔️ Leitura de bases CSV e Excel
✔️ Tratamento de dados
✔️ Agrupamento de informações
✔️ Análise de faturamento por loja
✔️ Formatação monetária em Real (R$)
✔️ Criação de gráficos
✔️ Manipulação de DataFrames com Pandas
